Acerca de MultiVentas

MultiVentas POS es un sistema de punto de venta desarrollado por Luis Alfonso Jaramillo, aprendiz del SENA, diseñado para facilitar la gestión de ventas, inventarios y clientes en negocios pequeños y medianos.

Versión 1.0 — Proyecto formativo del programa Análisis y Desarrollo de Software.

Quiénes Somos

Somos un equipo de estudiantes del del SENA, comprometidos con la innovación y el desarrollo de soluciones tecnológicas eficientes.

Este software fue creado como parte de nuestro proceso de formación, aplicando metodologías ágiles e integración de módulos funcionales.

Contáctanos

¿Tienes preguntas o sugerencias? ¡Nos encantaría escucharte!




Tratamiento de Datos

De acuerdo con la Ley 1581 de 2012, MultiVentas POS protege la privacidad y seguridad de los datos personales. La información recolectada se utiliza únicamente para la gestión de ventas y control de inventario.

El usuario puede solicitar la actualización o eliminación de sus datos personales en cualquier momento.

Para más información, consulte nuestra política completa de tratamiento de datos.
